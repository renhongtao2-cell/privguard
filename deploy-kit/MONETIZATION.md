# PrivGuard 变现分层（免费引流 → 付费破零）

> 原则：免费层获客（不花一分钱推广），付费层收钱。
> 付费层仍是 100% 本地处理，绝不收用户图片 —— 守住"不落库"铁原则。
> 不做主动推销/广告 —— 守住"不引流"铁律。

## 模型

```
搜"去水印"的人  ──(平台搜索)──▶  免费网页/插件  ──(试用满意)──▶  付费桌面版
   (自然流量)                        (获客,不收钱)                    (变现,破零)
```

## 免费层（获客，不收钱）

- 网页版去水印 + 背景移除（Cloudflare 托管）
- Edge / Firefox 插件
- 目的：被搜到、被试用、得好评、养自然排名

## 付费桌面层（变现，破零）

现有桌面原型：Flask + PyInstaller，本地 127.0.0.1:8765/8766 已验证。

| 版本 | 价格 | 差异点 |
|------|------|--------|
| 桌面版 One-time | $19 一次性 | 批量处理、更多 AI 模型、无水印导出、商用授权 |
| Team 年付 | $29/席/年 | 审计日志、团队共享、自托管许可 |

## 破零路径（按"1 个订阅 = 进展"标尺）

1. 上线免费层 → 平台自然搜索带来试用
2. 免费层加一行引导："需要批量 / 商用？升级桌面版 $19" + 购买按钮（Stripe / Payoneer）
3. 第一个真实付费 = 破零 = 验证产品成立

## 收款

- 国际：Payoneer（已有）/ Stripe
- 不接广告、不做 SEO 外链轰炸、不买量

## 注意

- 付费层同样 100% 本地，图片绝不上传服务器
- 所有获客来自平台自带搜索，不主动找客户
